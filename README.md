# 配送時間指定 管理ウェブアプリ（GAS）

配送の時間指定受付内容を記録し、検索・編集・削除・集計を行うGoogle Apps Scriptウェブアプリです。

## 機能

- **新規登録** - 時間指定の受付内容を登録
- **配送日検索** - 配送日を指定して一覧表示、編集・削除
- **集計** - 期間×担当者で件数・割合・最終発生日を集計

## セットアップ手順

### 1. Google Apps Script プロジェクト作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」を作成
3. プロジェクト名を「配送時間指定管理」等に変更

### 2. ファイル配置

- `src/Code.gs` の内容を GAS エディタの `コード.gs` にコピー
- GASエディタ左側の「+」→「HTML」から `Index` という名前のHTMLファイルを作成し、`src/Index.html` の内容をコピー

### 3. スプレッドシート設定

1. 新しいGoogleスプレッドシートを作成
2. スプレッドシートのURLからIDをコピー（`https://docs.google.com/spreadsheets/d/{ここがID}/edit`）
3. GASエディタで「プロジェクトの設定」→「スクリプトプロパティ」に以下を追加:
   - プロパティ: `SPREADSHEET_ID`
   - 値: コピーしたスプレッドシートID

### 4. 初期シート作成

GASエディタで `setupSheets` 関数を手動実行すると、必要なシート（時間指定DB / マスタ）が自動作成されます。

### 5. 担当者マスタ登録

スプレッドシートの「マスタ」シートのA列に担当者名（苗字）を登録してください。

### 6. デプロイ

1. GASエディタで「デプロイ」→「新しいデプロイ」
2. 種類: 「ウェブアプリ」
3. 実行ユーザー: 「自分」
4. アクセス権: 組織内のユーザー（推奨）
5. 「デプロイ」をクリック

| D | 配送日 | 日付 | |

| F | 伝票No | 文字列 | 6桁 |
| G | 指定区分 | 文字列 | |
| H | 指定時刻1 | 時刻 | |
| I | 指定時刻2 | 時刻 | |
| J | CS有無 | boolean | |
| K | 場所 | 文字列 | |
| L | 理由 | 文字列 | |
| M | 備考 | 文字列 | |
| N | 削除フラグ | boolean | 論理削除 |
| O | 削除日時 | 日時 | |
